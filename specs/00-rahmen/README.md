# Rahmen

Alles, was nicht zu einem einzelnen Spiel gehört: die Auswahl, die Navigation,
der Speicher, die gemeinsame Statistik, die Sicherung, der Offline-Speicher und
die Schnittstelle, über die sich ein Spiel anmeldet. Code in
[`app.js`](../../app.js), [`index.html`](../../index.html) und
[`sw.js`](../../sw.js).

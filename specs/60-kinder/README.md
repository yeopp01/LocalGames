# Für Kinder

Spiele für Kinder, die noch nicht lesen können – vom Baby, das auf ein Tier
patscht, bis zum Kindergartenkind, das Rufe erkennt. Dazu das Werkzeug, das
sie sich teilen: die Tiere mit ihren Aufnahmen und das Kinderzimmer, aus dem
nur Erwachsene wieder herausfinden.
